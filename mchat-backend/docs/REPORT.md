# Отчёт по техническому заданию

Статусы: **Выполнено** — код написан; **Проверено** — есть автоматический тест или прямое чтение кода, подтверждающее поведение;
**Нужен внешний доступ** — нужны ключи/устройство/сборочная среда. В этой среде (Linux-контейнер) НЕТ браузера Chrome, Android-устройства/SDK,
PostgreSQL и ключей ZEGO/Cloudinary, поэтому визуальные и «живые» сценарии на устройстве НЕ проверялись. Ниже это указано по каждому пункту.

| 2.1 | Стекломорфизм, убрать прямоугольные подложки | Выполнено. Визуально не проверено | **Причина прямоугольника у звезды:** свечение было `filter: drop-shadow` с анимацией; `#chat-name` имеет `overflow:hidden` (многоточие), и компоновщик Chrome обрезал тень по боксу — получался прямоугольник с жёсткими краями. ## Оставшиеся ограничения
1. Визуальные результаты (звезда, шапка, пузыри, панель записи), камера, звонки и PWA не проверены в реальном Chrome/на Android.
2. Вход через Google внутри APK не реализован.
3. APK не собран.
4. Профилирование производительности не выполнялось.
5. Бесплатный тариф Cloudinary ограничивает размер raw-файлов (см. `STORAGE.md`).
6. В архиве исходного проекта лежали посторонние файлы (`db` ~61 МБ, `6px`, `=`, `node:crypto`) и `.env` с реальными ключами — в ZIP они не включены; **ключи из `.env` стоит перевыпустить**, раз архив с ним передавался.
